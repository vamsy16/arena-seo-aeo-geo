# GEO + AEO Audit - AI Visibility (ChatGPT, Perplexity, Gemini)

You audit if brand is visible in AI answers (ChatGPT, Perplexity, Gemini, Claude) - NEW in 2026, huge opportunity.

## Definitions

- **GEO = Generative Engine Optimization:** Optimize to be cited by generative AI (ChatGPT, Perplexity, Gemini) when users ask questions
- **AEO = Answer Engine Optimization:** Optimize for answer engines (featured snippets, People Also Ask, AI overviews)

**Example:**
User asks ChatGPT: "What is best D2C bag brand in India?"
- If Zouk NOT cited = GEO leak = needs GEO
- If Zouk cited but no link = AEO leak

## When to Use

- User says "Is brand visible in AI?", "ChatGPT mentions brand?", "GEO audit"
- Brand ranks well on Google but not in AI answers

## 7-Point GEO/AEO Audit Framework

### 1. AI Citation Check (Manual Test - Most Important)

**Test yourself:**

Ask these in ChatGPT, Perplexity, Gemini:
- "What is best [niche] in [location]?" (e.g., "best skin clinic in Bangalore")
- "Top 5 [niche] brands in India"
- "Best [product] for [use case]"

**Check:**
- [ ] Is brand mentioned in AI answer?
- [ ] Is it in top 3 or buried?
- [ ] Is there a link to brand?
- [ ] Is description accurate or hallucinated?

**If NOT mentioned = HOT GEO lead (90% of Indian brands NOT cited)**

**Tools:**
- `ai-seo` skill (optimize for AI search, get cited by LLMs)
- Manual test via ChatGPT/Perplexity

### 2. llms.txt Check (New Standard 2025-2026)

**What is llms.txt?**
New file like robots.txt but for LLMs: `https://brand.com/llms.txt`
Tells AI what to crawl, what is important, brand description.

**Check:**
- [ ] Does https://brand.com/llms.txt exist?
- [ ] Does it have brand description, key pages, FAQs?
- [ ] 95% of Indian brands DON'T have llms.txt = huge GEO opportunity

### 3. Schema for AI (AEO)

AI loves structured data. Check for:

- [ ] FAQ schema? (Critical for AI answers)
- [ ] HowTo schema?
- [ ] QAPage schema?
- [ ] Speakable schema? (for voice assistants)
- [ ] Product schema with detailed attributes?

**No FAQ schema = AI can't extract Q&A = not cited**

### 4. Content for AI Citations

AI cites content that is:

- [ ] Clear, concise answers to questions (What is X? How to do Y?)
- [ ] FAQ page exists? How many FAQs?
- [ ] Comparison content? (e.g., "Zouk vs Mokobara")
- [ ] Definition content? (e.g., "What is D2C bag?")
- [ ] Authoritative (E-E-A-T: author bio, credentials)

**Check:**
- Does brand have /faq page?
- Does blog answer "What is best..." questions?
- Is content written in Q&A format?

### 5. Technical for AI

- [ ] Site crawlable by AI? (Check robots.txt not blocking GPTBot, PerplexityBot)
- [ ] Content not behind JS that AI can't render?
- [ ] PageSpeed fast? (AI prefers fast sites)

Check robots.txt for:
```
User-agent: GPTBot
Disallow: /
```
If blocked = AI can't crawl = not cited

### 6. Brand Authority for AI

AI cites authoritative brands. Check:

- [ ] About page with founder story?
- [ ] Press mentions?
- [ ] Wikipedia page?
- [ ] Social proof (reviews, testimonials)?

### 7. Competitor AI Gap

- [ ] Competitor cited in AI answer, you are not?
- [ ] Example: Ask Perplexity "best D2C bag" - Mokobara cited, Zouk not = gap

## Lead Scoring for GEO/AEO

Score /10:
- [3] NOT cited in ChatGPT/Perplexity for main niche query (most important)
- [2] No llms.txt file
- [2] No FAQ schema
- [2] No FAQ page / Q&A content
- [1] Robots.txt blocks AI bots

6+ = HOT GEO/AEO lead (90% of brands are 8-10)
